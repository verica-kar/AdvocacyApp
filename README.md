# Civil Advocacy App

This project is an Android application that helps users identify their local government representatives based on their current location or a user-provided address. By leveraging location services, the app retrieves and displays political officials across multiple levels of government in an interactive list. Users can view detailed profiles for each representative, including expanded images and additional information, providing an accessible way to understand local political representation.

## Tech Stack/Technologies
- Android Studio
- Java
- Html
- Git
- Google API

## Features
- Leverages location data to provide users with information about local government officials
  - Android Fused Location Provider to determine the user's location or input location
- Displays an interactive list of political officials that represent the current location, or input location, at each government level
- A full, detailed view of the individual government representative is displayed when an official's list entry is selected
  - Displays a larger version of the image when the image is clicked
